Initial implementation (2026-10-30): google.cloud.apigateway.v1 ApiGatewayService, Locations, IAMPolicy and Operations verified against cloud.google.com/go/apigateway v1.17.0 through the official client in the package tests; the data plane is verified against httptest backends and JWKS servers.

Verification pass (2026-10-30) against primary sources:

- docs.cloud.google.com/api-gateway/docs/openapi-overview: "API Gateway supports the following OpenAPI versions" 2.0, 3.0.x, 3.1.x; "supports all patch versions of 3.0 and 3.1".
- docs.cloud.google.com/api-gateway/docs/oasv3-extensions: x-google-backend "Required. You must set this extension for API Gateway."; x-google-api-management "Required", backends "Yes"; x-google-backend is a backend name; defaults APPEND_PATH_TO_ADDRESS (top level) and CONSTANT_ADDRESS (operation); deadline default 15 s, max 3600 s; x-google-auth lives in a Security Scheme Object (issuer, jwksUri, audiences, jwtLocations with header/query/valuePrefix); x-google-quota is a metric-to-cost map; "metrics and quotas apply to the whole API, not one API config".
- docs.cloud.google.com/api-gateway/docs/oasv2-extensions: "API Gateway applies the metrics and quota that you define here to the entire API rather than to an individual API config."; "If the address field is missing, path_translation will remain unspecified and it won't occur."
- docs.cloud.google.com/api-gateway/docs/troubleshoot: 500 {"code":500,"message":"Failed to call Service Control Quota."} when a quota metric no longer exists for the API.
- docs.cloud.google.com/api-gateway/docs/authenticate-api-keys: API Gateway "rejects requests unless the API key was generated in your Google Cloud project"; keys from other projects work if the API is enabled there.
- docs.cloud.google.com/api-gateway/docs/get-started-cloud-run: config creation "may take several minutes" and "up to ten minutes" for complex configs. The emulator's 2 s create and 1 s update/delete are a deliberate choice for tests (Timing is configurable), not an observation.
- github.com/GoogleCloudPlatform/esp-v2 (API Gateway's data plane): src/go/configgenerator/routegen/deny_all.go and deny_invalid_method.go (404 and 405 bodies), filtergen/http_connection_manager.go (local replies as {"code":..,"message":..}), tests/integration_test jwt_*, service_control_check_fail_test (400/403 key texts), service_control_quota_test (429 "RESOURCE_EXHAUSTED: "), backend_auth_disable_auth_test, jwt_locations_test, util.go (key query names key and api_key).
- github.com/google/jwt_verify_lib src/status.cc: the JWT status strings listed under api jwt.
- googleapis/googleapis google/cloud/apigateway/v1/apigateway.proto: resource patterns, openapi_documents vs grpc_services exclusivity, gateway_service_account as email.
