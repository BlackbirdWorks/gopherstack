Initial implementation (2026-10-31): google.cloud.resourcemanager.v3 Projects, Folders, Organizations, TagKeys, TagValues, TagBindings and google.api.serviceusage.v1 ServiceUsage, driven in the package tests through the official clients cloud.google.com/go/resourcemanager@v1.18.1 and cloud.google.com/go/serviceusage@v1.16.1 over gRPC and REST, plus raw v1 REST flows.

Primary sources used:

- cloud.google.com/go/resourcemanager@v1.18.1/apiv3 method and field comments: Project (project_id, display_name, labels), Folder (display_name regex, constraints), CreateFolder (height 10 active, 20 total, 300 children, unique display_name), DeleteFolder, UndeleteFolder, MoveFolder, DeleteProject, UndeleteProject, SearchProjects/SearchFolders/SearchOrganizations query grammar, TagKey/TagValue/TagBinding.
- cloud.google.com/go/serviceusage@v1.16.1/apiv1: ListServicesRequest.filter and page_size, BatchEnableServices atomicity and the 20-service limit, BatchGetServices 30-name limit, DisableService FAILED_PRECONDITION, CheckIfServiceHasUsage, REST paths in service_usage_client.go (/v1/{name=*/*/services/*}:enable).
- The Terraform google provider (hashicorp/google 8.5.0, as pinned by test/terraform/gcp) calls cloudresourcemanager v1 for google_project, data.google_project and google_project_iam_*, v3 for google_folder and tags, and serviceusage v1 (list with state:ENABLED, batchEnable, disable) for google_project_service; observed against this emulator by test/terraform/gcp/resourcemanager_test.go.

Enforcement (2026-10-31): --gcp-enforce-projects and --gcp-enforce-service-enablement (GCP_ENFORCE_PROJECTS, GCP_ENFORCE_SERVICE_ENABLEMENT) install a gRPC unary and stream interceptor (gcpenforce.NewServer, in 22 services' grpc.NewServer calls; REST reaches it through the gcprest transcoder) and an echo middleware (gcpenforce.EchoMiddleware, in the 6 HTTP-only services bigquery, compute, dns, identitytoolkit, sqladmin, storage). Project comes from request fields by proto reflection or the REST path; the API host from each service's google.api.default_host. Enforced: apigateway, artifactregistry, batch, bigtable, cloudbuild, cloudtasks, container, datastore, eventarc, firestore, functions, iam, kms, logging, monitoring, pubsub, redis, run, scheduler, secretmanager, spanner, workflows (gRPC and REST) and bigquery, compute, dns, identitytoolkit, sqladmin, storage (REST). Not enforced: this service itself.
